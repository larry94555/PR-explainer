PR Explainer settings

The model that answers questions in the chat. Explanations, Explain on hover and Explain ahead keep using Model, so a small fast model can explain while a bigger one answers questions. Opening the chat loads it ahead of the first question.

Lower gives steadier explanations; higher gives more varied ones.

Shorter answers arrive sooner. An explanation that reaches this limit is marked as cut off. Chat answers may run to 1024 tokens even when this is lower.

How much the model can read at once, prompt and answer together. Leave empty to size it to each explanation (2048 for most, up to the model's own size or 4096), which is faster and uses less memory. Long code is trimmed to fit.

How long Ollama keeps the model in memory after each explanation, so the next click does not wait for it to load. Opening a PR's Files changed tab also loads it ahead of the first click. 0 frees the memory after each answer and turns that off.

Starts explaining a line when the pointer rests on it for a moment, so a click often shows the answer at once. Only one line is explained ahead at a time, and moving to another line stops it. Off by default because it uses the model for lines you may not click.

When a PR's Files changed tab has been left alone for 2 seconds, explains changed lines before you click them, so a click is answered at once from the cache. Lines on screen explains the lines you can see, at most 30 lines per page. Whole PR works through every changed line of the PR, starting with the code on screen, then the files next to it, then the rest, at most 500 lines per PR in each tab and again after a new commit. Both wait while you click or chat and while the tab is hidden. Off by default because it keeps the model busy and uses battery.

How many explanations are sent to Ollama together. More than 1 only helps when Ollama is set to run several (OLLAMA_NUM_PARALLEL), and usually only on a GPU: on a CPU each answer gets slower and a click waits longer. A click always goes first.

Lets a reasoning model, such as deepseek-r1, think before it answers. Off by default: without thinking it answers much sooner, and a few lines of code rarely need it. Other models are not affected.

Shows explanations and chat answers word by word while the model writes them. Off by default: the answer appears whole once it is ready, so the sections do not jump around as they fill in.

Keeps explanations on this computer after Chrome closes, so a PR explained once is still instant the next day. An answer not used for this many days is removed, and at most 50 MB is kept. 0 keeps them only until Chrome closes.

Debug

Opens the popup's Details on the explanation's round trip, with the prompt sent to the model and its reply.

Keeps every request to GitHub and to the model (prompt, reply and time) in a log for the debug window. The log is kept in memory on this computer, holds the last 200 requests, and is cleared when Chrome closes or when you turn this off.

Speed

Times one short explanation on each installed coding model, with the settings above (including Context size, which changes how much fits on the GPU), and marks the fastest one that answers in under 2 seconds. The size of the model and whether it runs on the GPU make the biggest difference.

Privacy

Your code stays on this computer. PR Explainer reads code from GitHub and sends it only to the Ollama URL above, which must be on this computer. It sends nothing anywhere else: no analytics, no tracking.
